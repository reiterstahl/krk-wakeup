# KRK Wakeup

Planned native Windows utility to keep selected KRK speakers awake using periodic audio signals.

**Status:** research and planning. No application has been implemented or tested on hardware yet.

The first target is KRK GoAux 3 speakers connected through RCA and Windows 11 x64, with Windows 10 compatibility planned for later validation. Audio must target a user-selected output independently of the Windows default output, including while Bluetooth headphones are in use.

See [the initial plan](docs/PLAN.md) for findings, proposed behavior, validation, and open questions.

The repository is currently private, with a future public open-source release intended. The license is pending selection. This is an independent project, not an official KRK product.
